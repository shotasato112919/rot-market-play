# 腐相場 / ROT MARKET — ブラウザで遊ぶ

> **獲れるものは安い。高いものは、もう獲れない。**

**▶ https://shotasato112919.github.io/rot-market-play/**

魔物を狩って素材を持ち帰り、町で売る。ただし**素材は腐り、売れば値が崩れ、
狩れば獲物が減って値が上がる**。1つの種族を狩り続けることが構造的に成立しない。

制作中の個人開発ゲームの**試遊版**です。中身は開発中で、数値も釣り合いも変わります。

## 操作

| したいこと | キーボード | スマホ |
|---|---|---|
| 動く・狩る | 矢印キー（斜めはテンキー） | 十字キー（**角を押すと斜め**） |
| コマンドを開く・決定 | Space | A |
| やめる・閉じる | Esc | B |

**隠しキーはありません。** できることは全部カーソルで選べます。

## 最初の読み込みが遅いのは仕様です

ブラウザで Python を動かしているので、初回は **Python 処理系ごと約16MB**
（Pyodide 9.2MB ＋ 標準ライブラリ 2.4MB ＋ Pyxel 4.8MB）を CDN から取ってきます。
ゲーム本体は 83KB で、全体の0.5%しかありません。

「CLICK TO START」を押してから数十秒かかります。2回目以降はキャッシュが効きます。

## これは何でできているか

[Pyxel](https://github.com/kitao/pyxel)（Python のレトロゲームエンジン）製。
`pyxel app2html` で .pyxapp を base64 埋め込みした単一 HTML です。

日本語は [PixelMplus12](https://itouhiro.hatenablog.com/entry/20130602/font)
（作: Itou Hiroki）から必要な文字だけを 12×13px のドット絵に焼いて持っています。
ライセンスは M+ FONT LICENSE（同梱の `MPLUS_FONT_LICENSE_E.txt`）。
